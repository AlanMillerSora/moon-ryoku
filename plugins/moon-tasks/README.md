# Moon Tasks

Лунный список задач на сцене Ryoku: у каждого дела — серп, у сделанного — полная
Луна. Клик по строке переключает, текст в одну строку с многоточием.

## Что делает

- **Сервис** (`service/Main.qml`): читает `$XDG_STATE_HOME/ryoku/plugins/moon-tasks/tasks.json`,
  следит за файлом, переключает дело одним процессом `bin/moon-task` (тот держит
  `flock`, поэтому двойной клик не теряется) и сообщает об ошибке, если файл битый.
- **Виджет** (`content/Widget.qml`): заголовок «задачи», счётчик `сделано / всего`,
  строки с серпом и текстом, «ещё N» при переполнении. Своих окон не создаёт.
- **CLI** (`bin/moon-task`): `add`, `list`, `toggle <id>`, `done <id>`, `clear`.
  Первый аргумент — каталог состояния (его даёт виджет), второй — команда.

## Что читает и пишет

Только `tasks.json` в каталоге состояния плагина. Сети, `sudo`, композитора и
чужих файлов нет; внешние команды — `bash`, `jq` и `flock` (указаны в манифесте).

## Настройки

| ключ        | тип    | по умолчанию | описание                      |
| ----------- | ------ | ------------ | ----------------------------- |
| `limit`     | int    | `6`          | сколько строк показывать (1–24) |
| `showDone`  | toggle | `true`       | оставлять сделанные в списке   |

## Как добавить дело

```sh
bin/moon-task "$HOME/.local/state/ryoku/plugins/moon-tasks" add "позвонить в банк"
```

Виджет подхватит файл сам (следит за изменениями). Пока переключение
выполняется, второй клик игнорируется (`busy`), поэтому двойной клик — это одно
переключение, а не два.
