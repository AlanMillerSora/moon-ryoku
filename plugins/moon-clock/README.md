# Moon Clock

Лунные часы на сцене Ryoku: время внутри кольца синодического месяца.

## Что делает

- Кольцо — месяц в 29.5 суток, 30 делений (квартальные длиннее), светлая риска на
  половине — полнолуние, точка на кольце — текущий возраст Луны.
- Внутри: время `hh:mm`, возраст `5.1 / 29.5` и дата.
- Рисуется один `Canvas`, обновляется раз в минуту; собственных окон не создаёт —
  живёт в слое виджетов Ryoku.

## Что читает и пишет

Ничего: время берётся из системных часов, фаза — из локального сервиса
(`service/Main.qml`, та же математика Meeus, что у `moon-stage`). Сети, команд и
`sudo` нет.

## Настройки

| ключ       | тип    | по умолчанию | описание                    |
| ---------- | ------ | ------------ | --------------------------- |
| `showDate` | toggle | `true`       | показывать дату под временем |

## Установка

```
ryoku plugin add . --yes
ryoku-plugins-place moon-clock host desktopWidget
ryoku-plugins-place moon-clock desktopWidget 2528 420 1
```
