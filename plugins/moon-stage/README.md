# Moon Stage

Луна на сцене Ryoku: крупный серп текущей фазы, процент освещённости, возраст и
дата следующего полнолуния — прямо на обоях, рядом с часами.

## Что делает

- **Сервис** (`service/Main.qml`): та же математика, что у `moon-phase` — разность
  эклиптических долгот Луны и Солнца (усечённый ряд Meeus), освещённость
  `(1 - cos θ) / 2`, возраст от синодического месяца, следующее полнолуние
  делением пополам. Пересчёт раз в минуту.
- **Виджет** (`content/Widget.qml`): один `Canvas` с серпом и три строки текста.
  Ни анимаций, ни собственного окна: виджет монтируется в уже существующий слой
  `ryoku-widgets`, поэтому не создаёт полноэкранных прозрачных поверхностей и не
  ловит чужие клики.

## Что читает и пишет

Ничего: состояние в памяти, настройки — через `pluginApi.pluginSettings`. Сети,
команд и `sudo` нет.

## Настройки

| ключ          | тип    | по умолчанию | описание                              |
| ------------- | ------ | ------------ | ------------------------------------- |
| `showDetails` | toggle | `true`       | показывать возраст и следующее полнолуние |

## Установка

```
ryoku plugin add . --yes
ryoku-plugins-place moon-stage host desktopWidget
```

Дальше — перетащить по обоям и задать масштаб в **Ryoku Settings → Add-ons**
(или `ryoku-plugins-place moon-stage desktopWidget <x> <y> <scale>`).
