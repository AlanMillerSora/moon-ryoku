# Moon

Одни часы и одна Луна на сцене Ryoku.

## Что делает

- Кольцо — синодический месяц: 30 волосяных делений, каждое седьмое длиннее;
  светлая риска снизу — полнолуние.
- Метка на кольце — не точка, а маленький серп текущей фазы: он же показывает
  возраст Луны.
- Внутри — время; под циферблатом — название фазы (Fraunces) и процент.

Один `Canvas`, перерисовка раз в минуту, никаких анимаций и собственных окон:
виджет живёт в существующем слое `ryoku-widgets`.

## Что читает и пишет

Ничего: время из системных часов, фаза — локальный расчёт в `service/Main.qml`
(разность эклиптических долгот, усечённый ряд Meeus). Сети, команд, `sudo` нет.

## Настройки

| ключ          | тип    | по умолчанию | описание                       |
| ------------- | ------ | ------------ | ------------------------------ |
| `showPhase`   | toggle | `true`       | название фазы под циферблатом   |
| `showPercent` | toggle | `true`       | процент освещённости            |

## Установка

```
ryoku plugin add . --yes
ryoku-plugins-place moon host desktopWidget
ryoku-plugins-place moon desktopWidget 2528 420 1
```
