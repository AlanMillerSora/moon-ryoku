## 0.13.0 — 2026-11-17

- Исправлено: виджет `moon-tasks` показывал «пусто» и не переключал дела. Хост
  `desktopWidget` в 1.0.9 **не отдаёт `pluginApi.stateDir`** (он есть только у
  бара), сервис собирал `"undefined/tasks.json"`. Теперь путь берётся из
  `pluginApi.stateDir`, а если его нет — из `XDG_STATE_HOME`/`HOME` +
  `ryoku/plugins/moon-tasks` (тот же каталог R8). Проверено по логу:
  `Starting async load … /home/sora/.local/state/ryoku/plugins/moon-tasks/tasks.json`,
  виджет показывает `0 / 2` и оба дела.
- Версия плагина 0.1.1; `install-moon.sh` при смене версии переустанавливает
  плагин, позиция и настройки восстановлены (`3076,287`, `limit 6`).
