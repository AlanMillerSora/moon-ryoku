# CHANGELOG

## 0.5.0 — 2026-11-14

- P3 закрыт по-настоящему: сервис плагина не компилировался
  (`property int synodicDays: 29.530588853` → «Invalid property assignment: int
  expected»), поэтому виджет на баре всегда показывал 0 % и рисовал новолуние.
  Свойство стало `real`; проверено стендом (`frac=0.1445, illum=19.24 %,
  age=4.27 д, next full 24.11.2026 17:59`) и живым баром (серп + «19%»).
- Плагин: `assets/preview-widget.png` — настоящий снимок с бара (2×, grim);
  мёртвая функция `row()` убрана из панели, `letterSpacing` масштабируется,
  виджет и панель не рисуют ложные данные, пока сервиса нет. Панель проверена
  рендером с живым сервисом: фаза, `% · возраст`, «Next full».
- Найдено: `topbarGlyph`-плагин рисуется только на QS Bar; рейл `sumi` строится
  из фиксированного каталога `FrameBars/BarCatalog.js` и мест для плагинов не
  имеет. Записано в README и `docs/FINAL_REPORT.md`; решение за Аланом.
- CPU-гейт: 60 с с плагином 5.30 с, без — 5.29 с → дельта 0.017 % ядра (< 0.2 %).
- P4 (без публикации): `docs/README.md` — установка, откат, форк, шрифты, обои,
  ограничения; запись плагина собрана `ryoku plugin export` и проходит
  `tests/validate-catalogue.sh` в клоне ryostore (`store catalogue OK`).
- Шрифты: трио (`Space Grotesk` / `Space Mono` / `Fraunces`) записано в рис;
  гейт 15 px провален по покрытию (нет кириллицы в Space Grotesk и Fraunces,
  Space Mono не установлен) → UI остаётся на mono, это оговорённый откат.
- Рис теперь владеет `look.shell.frameBars.rails` — до этого sumi-рейлы брались
  из конфига пользователя, а `look.shell.bars` (модель QS Bar) на sumi не
  рисуется вообще.
- P5: `docs/MAINTAINING.md` — процедура поддержки после релизов Ryoku.
- P6 (опция): палитра `Moon Warm` (селенит `#E3CFA6`) в `src/palette.warm.json`;
  `tools/build-rice.sh` собирает все `src/palette*.json`, `check-contrast.py`
  проверяет каждую палитру (все пары AA). Схема в v1 не ставится.
- Гейт применения нового риса: `frameBars` и шрифтовое трио применились (правый
  рейл с колоколом, gapps 12, rounding 6), но `rice restore previous` **не**
  вернул `desktop.appearance` (`desktop.json` 6313 → 72 байта, живые gapps/
  rounding упали на значения модулей до 16/8/4). Восстановлено вручную:
  копия `desktop.json` + `ryoku-hub desktop preview`; дефект инструмента —
  в `docs/FINAL_REPORT.md`.
- Публикаций нет.
