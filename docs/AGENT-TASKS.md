# Todo API для агентов

Виджет `moon-tasks` держит один список дел, и агенты (я, другие ассистенты)
пишут в него тем же CLI, что и человек. Никакого сокета, сети или ключей:
файл + команда под `flock`. Виджет следит за файлом и обновляется сам.

## Где лежит

```
$XDG_STATE_HOME/ryoku/plugins/moon-tasks/tasks.json   # по умолчанию ~/.local/state/…
```

Формат — массив объектов, порядок = порядок в виджете:

```json
[
  { "id": 1, "text": "проверить ревью риса", "done": false, "at": 1794885650, "by": "agent" }
]
```

`id` — целое, уникальное (следующий = max+1); `at` — unix-время; `by` —
необязательная метка источника (`agent`, `alan`, любая строка).

## Команды

Все команды принимают каталог состояния первым аргументом. Короткая обёртка
`~/.local/bin/moon-task` подставляет его сама.

```sh
moon-task add "текст"                    # добавить (id вернётся только с --json)
moon-task add --json --by agent "текст"  # -> {"id":3,"text":"…","done":false,…}
moon-task list                           # человеческий список
moon-task list --json                    # массив задач одной строкой
moon-task done 3                         # отметить выполненной по id
moon-task done --text "ревью"            # …или по подстроке текста (без регистра)
moon-task toggle 3                       # переключить
moon-task remove 3 | --text "ревью"      # удалить
moon-task clear                          # убрать все выполненные
```

Без обёртки:

```sh
~/.local/share/ryoku/plugins/moon-tasks/bin/moon-task \
  ~/.local/state/ryoku/plugins/moon-tasks add --json --by agent "текст"
```

## Правила для агента

1. **Одна задача — одна строка.** Пиши по-русски, коротко, в форме действия:
   «переснять карточку Store», а не «карточка».
2. **Не дублируй.** Перед `add` сделай `list --json` и проверь, что такой
   задачи нет (сравнивай по смыслу, не по точной строке).
3. **Отмечай сразу, как сделал:** `done --text "<ключевые слова>"`. Это
   единственный способ, которым человек видит прогресс.
4. **Не переписывай файл руками** и не удаляй чужие строки: всё через CLI, он
   держит `flock`. Ручная правка возможна, но пиши атомарно (`jq … > file.new
   && mv`) и только когда виджет не работает.
5. **Не клади секреты.** Файл читается другими инструментами и может попасть в
   скриншот.

## Коды выхода

| код | что значит |
| --- | --- |
| 0 | сделано |
| 2 | нет аргументов / неизвестная команда |
| 3 | `--text` не нашёл ни одной задачи |

## Если файл битый

CLI сам уводит его в `tasks.json.broken` и начинает список заново — виджет при
этом не падает, а показывает предупреждение в служебной строке лога.
