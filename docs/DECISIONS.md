## Внешний вид

| Вопрос | Решение |
|---|---|
| Палитра v1 | холодный монохром, акцент `#E7E9EE`; тёплый селенит `#E3CFA6` — отдельная запись `Moon Warm` в P6 |
| Бар | встроенный `sumi`: рамка по краям + два рейла |
| Композиция | лево: launcher, workspaces, clock; право: audio, network, battery, status, tray |
| Плотность | база 15 px (как в шелле Алана), шрифт не форсим |
| Типографика | три голоса системы: Fraunces (дисплей), Space Grotesk (UI), SpaceMono (метки); шелл — системный mono, семейство не форсим |
| Радиусы и ритм | радиус 6 (как в Hub/Store), border 1, сетка 4/8/12/16/24/32/48, blur off, тень off |
| Цвет обоев | `color: fixed` + `palette.json`, чтобы монохром не плыл за обоями |
| Печать бренда | 月 (универсально: и луна, и месяц), в `layers.brand.markText` |
| Зерно | 0.10, только на превью и обложке Store, никогда под текстом |
| Обои | v1 отклонены 14.11.2026. Ассет делает сам Алан (найдёт фото или сгенерит), не мы; P4 ждёт файл |
| Палитра | v1 — только холодный Moon; `Moon Warm` (`#E3CFA6`) — отдельная запись в P6 |
| Ультравайд | рис универсальный; `moon-ultrawide` — личный fork Алана, не в магазин |
| Виджеты | в v1 только бар (`topbarGlyph`); виджеты на сцене — позже, отдельными записями |
| Локскрин | отложен (P6), в v1 не делаем |
| Печать 月 | только карточка Store; в рис не протаскиваем (capture 1.0.9 не пишет layers) |
| Скриншоты | отложены: делаем отдельным заходом, не в P4 |
| niri | в README честно: поддержка заявлена, проверка скоро (пункт «niri soon») |
| Иконки трея | монохром (`tray.monochromeIcons: true`) |

## Технические рамки

| Вопрос | Решение |
|---|---|
| Композиторы | Hyprland и niri; в рисе обе ветки `look.wm`, плагин без обращений к WM |
| Что владеет рис | только whitelist из `docs/PLAN.md` §4; полный `capture` запрещён |
| Генерация | `rices/moon/rice.json` и `colorschemes/Moon/Moon.json` собираются из `src/` |
| Зависимости кусков | нет: рис самодостаточен, куски — отдельные записи |
| barstyles | в v1 не делаем; встроенный `sumi` покрывает лук |
| Плагин | только Quickshell API, без сети, `sudo` и `hyprctl`; состояние в `stateDir` |
| Минимальная версия Ryoku | та, на которой снят рис (`createdWith`), проверка — P5 |

## Поддержка

- Автор — Alan; обновления после релизов Ryoku (smoke `apply`/`restore`, бамп версии).
- Если item перестаёт работать и починить некому — item снимается из реестра, а не
  остаётся сломанным (требование CONTRIBUTING магазина).
- Багрепорты: issues в `upstream`-репозитории.
- Печать бренда — кандзи 月, как печати категорий в Store (飯, 色, 棒…).

## Открытые вопросы, закрытые по умолчанию

1. Ультравайд-вариант — отдельный fork-рис `moon-ultrawide`, основным не делаем.
2. Плагин — только в баре; виджет на сцене добавим в P6, если попросят.
3. Локскрин — не входит в v1.
4. Радиус — 6 (как в Hub и Store), решено 14.11.2026.
5. Печать — 月, решено 14.11.2026.
6. Публикация — уточняется: один PR с тремя items, или рис+тема одним PR, а плагин отдельным
   (плагин проходит отдельный security review). Рекомендация: рис+тема вместе, плагин отдельно.
