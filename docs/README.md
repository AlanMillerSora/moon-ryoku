# Установка, настройка, откат

Черновик: заполняется в P4 вместе со скриншотами. Пока — то, что уже верно.

## Установка

1. Ryoku Hub → Store → Rices → **Moon** → Install (или Apply).
2. Рис заменяет бар, тему, виджеты сцены и обои; текущий вид сохраняется в бэкап.
3. Плагин фазы Луны ставится отдельно: Store → Plugins → **Moon Phase**, затем
   включить и поставить на бар.

## Откат

```sh
ryoku-hub rice restore previous
```

Возвращает состояние до применения риса. Если рис изменён после установки —
изменения теряются, как и у любого другого риса.

## Настроить под себя

| Что | Где |
|---|---|
| Радиусы, гэпы, границы | Ryoku Hub → Appearance |
| Палитра | Store → Themes → **Moon** |
| Позиции и виджеты бара | QS Bar Settings (Super+comma → Bar, или лого бара) |
| Обои | `Super+W` |

Своя копия с правками:

```sh
ryoku-hub rice fork moon
```

## Требования

- Ryoku с встроенным баром `sumi`. На версиях без него shell откатывается на
  `orpheus` — лук останется рабочим, но вид бара будет другим.
- Шрифты: Inter Display и Iosevka (входят в Ryoku).
- Обои идут отдельным ассетом и ставятся вместе с рисом.
