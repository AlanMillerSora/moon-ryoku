# refs/walls — обои-референсы

Сюда кладутся картинки, из которых собирается обои Moon. Это **не** ассеты риса:
в `rices/moon/` они не попадают, в магазин не уезжают, `build-store.py` их не
видит.

| файл | откуда | что это |
| --- | --- | --- |
| `angel1-2248x1096.png` | обои, которые Алан поставил 14.11.2026 (`~/Pictures/Wallpapers/Angel1.png`, sha256 `bc3086…6174`) | исходник для лунной темы: один источник света, крылья, гало. Права — у автора картинки; файл лежит здесь как личный референс, а не как распространяемый ассет. |
| `angel1-moon-candidate.webp` | `tools/make-wall.py` из файла выше, 2560×1440 | кандидат обоев: монохром, холодные тени, гало как единственный свет, вигнет и зерно 0.10. Не финал — Алан делает свою версию. |

Как из такого исходника делается обои риса — `tools/make-card.py` (для карточки)
и будущий `tools/make-wall.py`: обесцветить, остудить тень, вигнет, зерно 0.10,
16:9 из 21:9 или наоборот, без кропа луны и лица.
